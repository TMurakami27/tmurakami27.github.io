Portfolio / Project

AI job-hunt tool with cover letters

Columbia class project · 2026

Context

In a Columbia class, I used Claude Code in VS Code to work from a folder with my resume and four job postings.

What I did

  • Turned the folder into a local web page that lists each role with its key facts, fit with my CV, deadline and interview questions.
  • Extended it to draft a one-page cover letter for each role, with a fact-check table that traces every claim to my resume or the posting, and a plain-English rulebook the agent follows.

Result

A self-audit and an independent review found mistakes, invented details and a generic opening. I fixed them by adding rules and rebuilding every letter.
